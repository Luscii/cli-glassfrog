## Phase 1: The `tension update` command [Shared]

- [ ] **T001** [Shared] [P] Add the `TensionUpdateInput` partial-update request type + `NewTensionUpdateInput` in `internal/glassfrog`
  - **Scope**: In `internal/glassfrog/tension.go`, add a **new** request-input type for `updateTension` — the nested envelope `{"tension": {"body"?, "label"?, "status"?, "meeting_type"?}}` with **all four inner fields `omitempty`, including `status`** — plus a `NewTensionUpdateInput(body, label, status, meetingType string)` constructor (the `NewTensionInput` shape, over the four-field all-`omitempty` body). This is a **sibling of, not a growth of, capture's `TensionInputBody`** (plan ADR-1): leave `TensionInput`/`TensionInputBody`/`NewTensionInput` (042) **byte-stable** — capture must keep its "no `status` field / `Body` non-`omitempty`" invariant. Explicit snake_case JSON tags (encoding/json does not bridge underscores). No transport, no cobra; the `Tension` response model and `Document[Tension]` are reused unchanged. The constructor receives already-resolved (presence-filtered) values and relies on `omitempty` to drop the unsupplied ones — no pointer fields (every supplied value is non-empty by the command's validation, so there is no empty-vs-absent ambiguity to model).
  - **Acceptance criteria**:
    - `NewTensionUpdateInput("b","","archived","")` marshals to `{"tension":{"body":"b","status":"archived"}}` — only the supplied non-empty fields, `status` included
    - `NewTensionUpdateInput("","","","")` marshals to `{"tension":{}}` (all `omitempty`) — the command guarantees this case never reaches the marshaller (precondition in T002), but the type's omit behavior is pinned
    - A supplied value for each of `body`/`label`/`status`/`meeting_type` appears under the correct snake_case key
    - Capture's `TensionInput`/`TensionInputBody`/`NewTensionInput` are unchanged (a byte-stable test or unchanged 042 tests confirm it); `go build`/`go vet` clean
  - **Dependencies**: None — a new type beside the landed `Tension`/`TensionInput` (042 on main). Startable immediately.
  - **Plan reference**: Phase 1 (the command); ADR-1 (new `TensionUpdateInput`, all-`omitempty` incl. `status`; capture input left byte-stable)
  - **Interface references**: interface-spec.md — `internal/glassfrog` partial-update request input (`TensionUpdateInput`/`NewTensionUpdateInput`)
  - **Scenario references**: tension-update.feature: "A partial update sends only the supplied fields and no precondition" (the input type is the mechanism)
  - **Risk**: ⚠️ FORK, do not grow — adding `Status`/`Body omitempty` to capture's `TensionInputBody` would erase capture's type-level "cannot send server-owned status" guarantee (plan ADR-1). ⚠️ All four fields `omitempty` (including `status`, unlike capture). ⚠️ Leave 042's capture input byte-stable.
