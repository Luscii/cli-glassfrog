# Gated-command registry — the proposal write path (063 Write-Safety Guardrail).
#
# THE single source of "what is a governance write", consumed by BOTH:
#   - the PreToolUse gate script  (plugin/hooks/glassfrog-write-gate.sh)
#   - the drift tripwire          (internal/build/write_safety_guardrail_guard_test.go)
# so the two can never disagree about which commands must be gated (plan ADR-4).
#
# Each non-comment, non-blank line is a `glassfrog proposal` write leaf that MUST
# be gated behind explicit human confirmation before it runs. This file lists
# EXACTLY the proposal-write leaves — no reads (`proposal get` / `proposal list`)
# and no operational tension commands (`tension create|update|discard`), which
# pass through ungated.
#
# Adding a new proposal write command to the CLI? Add its leaf here. Until you do,
# the gate fail-closes it (an unrecognized `proposal` subcommand is asked, not
# waved through) and the drift tripwire turns CI red — a new write cannot silently
# ship ungated.
