# (`domains`/`policies`/`policy` are top-level, not `roles` subcommands).
# These are reads only — no write leaf (proposal/tension writes) ever appears
# here; the path never writes.

# agent artifact must name each one — a constraint-discovery artifact must
# never name a read the CLI no longer exposes, so a rename or drop in the CLI
