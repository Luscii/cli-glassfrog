# Composed-leaf registry — the commands the Proposal Impact Review Path composes.
#
# THE single source of "which glassfrog leaves the impact-review path composes",
# consumed by BOTH:
#   - the proposal-impact-reviewer agent (plugin/agents/proposal-impact-reviewer.md)
#     — its "Composed reads" section names exactly the NINE read leaves below and
#       no others; the tenth leaf (`proposal respond`) is the skill's, never the agent's
#   - the proposal-impact-review skill (plugin/skills/proposal-impact-review/SKILL.md)
#     — its decision-and-respond step runs the ONE gated write leaf below, in the
#       caller's context, only on an explicitly operator-chosen value
# so the artifact prose and this registry can never disagree about the composed
# surface or its gate posture (mirroring the write-safety gate's
# gated-commands.txt, plugin/hooks/gated-commands.txt, and the sibling
# composed-leaf registries in plugin/agents/).
#
# Each non-comment, non-blank line is ONE `glassfrog` leaf the path may invoke,
# written as a command path: two-token `proposal <sub>` / `me <sub>` pairs are
# written like the write-safety gate's registry lines (so the two read like with
# like); bare `me` and the top-level reads are single tokens (`domains` and
# `policies` are top-level commands — `domains <role-id>`, `policies <role-id>` —
# not `roles` subcommands). Nine are review reads (the grounding/situating
# proposal reads, the four footprint reads, the three affected-governance
# read-backs); one is the gated governance write the write-safety gate confirms
# by design (`proposal respond`), run only through the confirmed write flow and
# belonging to the SKILL's caller-context step, never the agent's composed reads.
# No other proposal write ever appears here — the path never creates a proposal
# (that is the proposal-drafting path) and never advances or withdraws one (that
# is the proposal-circulation path).
#
# The one-in-nine-out gate posture this registry promises holds only while
# `proposal respond` is listed in the write-safety gate's registry
# (plugin/hooks/gated-commands.txt) and the nine reads are ABSENT from it — so a
# rename or drop in the CLI, or an edit to either registry's membership, means
# revisiting both files and both consumer artifacts together; the artifacts must
# never name a command the CLI lacks or a write the guardrail stops confirming.
